# Retail Sales Performance & Customer Segmentation

**Data Analytics | Python, Pandas, SQL**

All data in this project is **SYNTHETIC** — generated by `analysis.py` (seed 42). No real customer data.

## What it does
Generates 1,500 synthetic retail orders, analyses revenue, average order value (AOV), monthly trend and top products/categories, and builds RFM customer segmentation. SQL equivalents are in `sql/queries.sql`.

## Run
```bash
pip install -r requirements.txt
python analysis.py
```

## Results (actual run output, `results/summary.json`)
- Orders: **1,500** | Customers: **299**
- Total revenue: **£360,215.00** | AOV: **£240.14**
- Top category: **Electronics (£231,193.00)** | Top product: **Laptop (£164,517.00)**
- Best month: **2025-04 (£33,417.00)**
- RFM segments: Champions 75, Loyal 186, Regular 29, At Risk 9
